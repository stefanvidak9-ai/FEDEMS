# Chronological splitting and CNN-ready data (Person A)

Shared forecast target dates run from 2022-02-10 through 2022-12-21, with one gap. Chronological split: train 203 days (through Aug 31), validation 59 days (Sep–Oct), test 45 days (Nov–Dec). Each of 17 clients has train `(203,4,7)`, validation `(59,4,7)`, test `(45,4,7)`, with targets `(N,)`. Normalization means/std are computed from training data only. Outputs are in `Dataset/processed/building_<id>/{train,validation,test}.npz` and `Dataset/processed/global_scaler.json`. `python -m src.data.splitting` and `python -m src.data.preprocessing` regenerate the split index and final processed data. These scripts may overwrite generated outputs if run; do not rerun without intending to regenerate. See `step21_temporal_split.md` and `step23_cnn_ready_data.md`.
