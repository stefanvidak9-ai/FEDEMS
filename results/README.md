# Generated Results

Phase 6 Steps 32–34 write experiment outputs under `results/phase6/`. Each
step records per-epoch normalized training loss, validation/test MAE and RMSE
in kWh/day, target-date predictions, checkpoint(s), training configuration,
and Step 30 baseline comparisons. The centralized and local runs also record
per-building and pooled results.

These are generated artifacts and are ignored by Git. Run commands and the
input data contract are documented in [Phase 6](../docs/phase6/README.md).
The checked-in synthetic Step 30 example is test data only and must not be
presented as a COFACTOR result.
